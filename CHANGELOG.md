# Changelog

All notable changes to Tidemark are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and Tidemark uses
[Semantic Versioning](https://semver.org/).

## 0.1.0 - 2026-11-16

### Added

- Usage limits and spend in the menu bar for Claude, OpenAI, Copilot, Cursor, Antigravity, xAI, OpenRouter, Warp,
  DeepSeek, Kimi, z.ai, MiniMax, Ollama, OpenCode and ElevenLabs: every account side by side in one item, or an item
  per account.
- Per account: labels, progress bars and percentages in the menu bar, each optional; a thin line in the provider's
  colour once more than one provider is set up.
- A Liquid Glass panel with a tab per provider, keyboard shortcuts to switch tabs, and every account of the shown
  provider highlighted in the menu bar.
- History of limits and daily costs over 24 hours, a week, a month, a year or all of it.
- API organisations' costs with an admin or management key.
- Notifications as limits run low.
- Independent sign-in per account, credentials in the login keychain.
- Self-updates from the clone, automatically, download only or manually.
- `make uninstall`, which removes Tidemark, everything it stored and then the clone, after listing it all.
